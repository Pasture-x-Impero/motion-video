# Ferdige videoer

Rendret fra kildekoden i `src/`. Lag nye med `npm run render:intro`, `render:intro:wide`,
`render:tagline` og `render:tagline:wide` (de havner i `out/`).

| Fil | Innhold | Format | Bruk |
|---|---|---|---|
| `impero-intro-social.mp4` | Tre spørsmål → ringene → Impero ikon → logo → «Din IT-avdeling» | 1080×1350 (4:5) | LinkedIn, Facebook, Instagram |
| `impero-intro-wide.mp4` | Samme | 1920×1080 (16:9) | Nettside, YouTube, presentasjoner |
| `impero-tagline-social.mp4` | Logo → «IT-avdelingen for små og mellomstore bedrifter.» → «Vi hjelper deg å jobbe smartere med IT.» → logo med impero.no | 1080×1350 (4:5) | LinkedIn, Facebook, Instagram |
| `impero-tagline-wide.mp4` | Samme | 1920×1080 (16:9) | Nettside, YouTube, presentasjoner |

Postetekst til introvideoen ligger i `copy/linkedin-introvideo.md`.
